## 🚀 Flagship Builds

### 🏎️ &nbsp; RaceJudge — F1 Stewards' Precedent Engine
> *The only searchable, evidence-linked FIA decision corpus in existence.*

A production-grade F1 stewardship intelligence platform, built from scratch.

- 📄 Scraped, parsed & structured **1,085 FIA decision PDFs** (2019–2025) via a **Playwright + pdfplumber** pipeline with SHA-256 dedup — linked to race-control messages, team radio (**Faster-Whisper** ASR + **pyannote** diarisation) & lap telemetry.
- 🔍 Hybrid **BM25 + BGE-M3** semantic search with **RRF** over a **pgvector HNSW** index; a calibrated **XGBoost** 7-class penalty predictor with ECE/F1 validation gates.
- ⚡ **Next.js 15** app (10+ pages) + **FastAPI** (9 routers, 20+ endpoints) with a **WebSocket + Redis Pub/Sub** live race mode serving top-5 precedents in **< 5s** — **132 passing tests**, green CI, IaC via **Terraform + Fly.io + Prefect**, tiered monetisation.

`Python` · `FastAPI` · `Next.js 15` · `pgvector` · `XGBoost` · `BGE-M3` · `Prefect` · `Terraform`
&nbsp;→&nbsp; **[github.com/racejudge-hq/racejudge-web](https://github.com/racejudge-hq/racejudge-web)**

### 🧬 &nbsp; NeuroSynth v2 — Clinical AI Platform
> *Calibrated ensemble inference with explainability & fairness enforcement.*

- 🧠 A **5-model calibrated ensemble** (RF, GBM, XGBoost, LogReg, CatBoost) stacked with an out-of-fold meta-learner; isotonic calibration + **MAPIE** conformal intervals → **AUC 0.82, ECE 0.020, SHAP stability ≥ 0.60 Jaccard**.
- ⚖️ Enforced demographic fairness (parity, equalized odds) against **FDA SaMD / EU AI Act** thresholds with automated **PROMOTE / REJECT / HUMAN_REVIEW** gates; **FHIR R4**, ICD-10 & version-traceable PDF export; Helm + Terraform + Kubeflow.

`Python` · `scikit-learn` · `XGBoost` · `CatBoost` · `FastAPI` · `SHAP` · `MAPIE` · `Kubeflow`
&nbsp;→&nbsp; **[github.com/DisturbedSage5840C/NeuroSynth](https://github.com/DisturbedSage5840C/NeuroSynth)**

### 🧹 &nbsp; UHMS — University Housekeeping Management System
> *A deployed, full-stack campus hygiene operations platform.*

- 🏢 **4 role-based dashboards** (Admin, Supervisor, Staff, Resident) — photo-verified cleaning logs, 6-item per-washroom checklists, AI-assisted complaint prioritisation & supply inventory across **5 buildings**.
- 📱 Shipped a companion **Android APK** via EAS Build; deployed on Render.com.

`Node.js` · `Express` · `PostgreSQL (Neon)` · `Redis` · `Knex.js` · `React Native + Expo`
&nbsp;→&nbsp; **[github.com/DisturbedSage5840C/uhms](https://github.com/DisturbedSage5840C/uhms)**

### 💊 &nbsp; RWE Tracker — Real-World Evidence Perception Platform
